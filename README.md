Sistema web desarrollado utilizando HTML, CSS, JS y PHP para la gestión de ventas en línea y administración de inventario de una joyería, con funcionalidades para clientes y administradores.

🚀 Características

👨‍💼 Administración
✅ Gestión de tiendas/sucursales (crear, actualizar, consultar)

✅ Gestión de líneas de artículos (crear, actualizar, consultar, deshabilitar)

✅ Gestión de usuarios (clientes y administradores)

✅ Modificación de datos de usuarios y cambio de contraseñas

✅ Deshabilitación de artículos (sin eliminación permanente)

👤 Clientes
✅ Registro en línea (sign-up) obligatorio para comprar

✅ Actualización de datos personales y contraseña

✅ Consulta de historial de compras

✅ Compra en línea con generación de comprobante (pantalla + PDF)

📊 Reportes y Finanzas
✅ Estado de cuenta entre dos fechas (resumen de ventas)

✅ Reporte de ventas por tienda (pantalla + PDF)

✅ Resumen de artículos vendidos por rango de fechas

✅ Listado de artículos deshabilitados (pantalla + PDF)

🔐 Seguridad y Usabilidad
✅ Contraseñas almacenadas con hash

✅ Roles diferenciados: Administrador (0) y Cliente (1)

✅ Interfaz amigable con validación de formularios

✅ No se eliminan usuarios, solo se deshabilitan artículos

🛠️ Stack Tecnológico
Backend: PHP puro

Frontend: HTML + CSS + JS

Base de datos: MySQL 8.0

Generación de PDF: TCPDF
